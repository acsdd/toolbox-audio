# Release notes

## 0.2.0 — 2026-11-15

- Bundled ArtistWave 3.4 interface and Electron runtime; no separate runtime installation required.
- Google desktop OAuth using the system browser, PKCE and a temporary loopback callback.
- Navidrome library connection, recent albums, artist/album search, paging and playback.
- Plex browser sign-in, music-library selection, album search, paging and direct playback.
- Encrypted server credentials, narrow native bridges and credential-free renderer media URLs.
- Full-height Mini Player at the right screen edge, visible pin toggle and saved-playlist selection.
- Restores the previous full-window bounds and keeps playback in one session.
- Updated packaging excludes previous build outputs. Release workflow prepares draft artifacts and checksums.

Windows previews are unsigned. Online sources and NAS libraries require access to their respective services.
